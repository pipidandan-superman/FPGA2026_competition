# EES331 BLE Console v1.0 使用说明

## 启动

双击 `EES331_BLE_Console.exe`。本目录是完整的独立运行包，不需要安装 Python；请勿只复制 EXE，必须保留 `_internal` 目录。

## 已确认的板载蓝牙参数

- 设备名称：`MLT-BT05`
- 当前设备地址：`6A:C2:D2:F2:1B:5D`
- 串口透传服务：`0000FFE0-0000-1000-8000-00805F9B34FB`
- 串口透传特征：`0000FFE1-0000-1000-8000-00805F9B34FB`
- FFE1能力：读取、带响应写、无响应写、通知
- 当前枚举MTU：23字节；单次无分包有效载荷按20字节以内使用

## 首次通信验证

本板卡已实测支持未配对GATT通信。直接在本上位机扫描并连接，不需要先在Windows
“添加蓝牙设备”中输入PIN。2026-09-12的未配对读取与55写入均成功；此前加密配对
状态出现连接后迅速断开。如看到系统PIN窗口，可取消并回到本上位机。

1. 给EES-331上电并等待蓝牙模块启动。
2. 打开程序，点击“扫描”，在设备列表选择 `MLT-BT05`。
3. 点击“连接”。连接成功后程序会自动显示全部GATT服务和特征。
4. 选择FFE1特征，点击“订阅通知”。
5. 在FPGA的ILA中先配置并启动 `rx_done == 1` 触发。
6. 程序选择HEX模式，输入测试字节（例如 `55`），点击“发送一次”。
7. 在ILA中核对 `rx_done` 和 `rx_data[7:0]`；本步骤只验证PC到PL方向。
8. 验证PL到PC方向时，由PL UART发送已知字节，并在程序实时日志中核对收到的HEX值。

## 实时参数与扩展

### 新版 PL 串口桥：无需 ILA 的复现方式（2026-09-12 实测）

本节适用于已下载 ble_uart_debug_top.bit 的板卡。上面的 ILA 步骤属于旧 AT/ILA 版本。

1. 直接在本程序扫描并连接 MLT-BT05，不先在 Windows 中输入 PIN 配对。
2. 选择 FFE1 并订阅通知；使用另一个串口助手打开 COM4：9600、8N1、无流控。
3. 两个工具均选择 HEX、无后缀、关闭本地回显；先关闭周期发送。
4. 蓝牙工具发送 55 AA 31 32 00 FF，串口接收应逐字节相同。
5. 串口工具发送 AA 55 32 31 FF 00，蓝牙通知接收应逐字节相同。
6. 任一方向错误或断连立即停止并保存收发日志。连接期间不要发送 AT 配置指令。

本机经用户批准移除仅 MLT-BT05 的配对后，上述两方向及重复测试共11轮通过，
61.703秒内每方向166字节一致。结束断开为测试程序主动操作，不是链路故障。
这是短时、分方向轮流收发验证，不代表长期稳定或同时满速双工通过。
若再次出现“连接后立即断开”，先保存日志；不要盲目重配对、改PIN或恢复出厂。
详见项目 4_metrics/logs/2026-09-12_ble_bridge_duplex_run01/REPORT.md。

- 设备地址、名称过滤、服务UUID、写特征UUID、通知特征UUID均可修改。
- 支持HEX和UTF-8两种编码，可选无后缀、CR、LF或CRLF。
- 支持带响应/无响应写入、单次发送和周期发送，周期参数修改后用于下一次发送。
- 命令预设保存在配置文件中，便于以后增加机械臂命令、寄存器读写帧和状态查询帧。
- 通信记录可导出为JSONL，便于复现和分析。
- 用户配置保存于 `%LOCALAPPDATA%\EES331_BLE_Console\config.json`。

## 参数边界

GUI中的连接和传输参数可以实时修改。模块名称、PIN、UART波特率、主从角色等属于MLT-BT05的AT参数，通常要求BLE未连接，并由PL侧UART配置桥发送对应AT指令；它们不是普通GATT连接期间可直接修改的参数。

## 停止条件

如果无法连接、FFE1没有枚举出来、写入后ILA未出现 `rx_done`、数据与发送内容不一致，或出现持续断连，请停止后续控制联调并保存程序JSONL日志和ILA截图，不要直接进入机械臂控制测试。
