# EES-331 动作控制测试版 v1.0

本地离线构建/自检已通过，并已与PL重加载器v1.4完成两轮上板验证；第二轮由用户确认发生在断电重启后。当前是2/2样本，不代表长期可靠性。
Git交付使用本目录中的启动脚本复用相邻`EES331_Gesture_Viewer_v1.0`的完整运行目录，避免重复提交约761MB依赖。两个目录必须保持同级，并先执行`git lfs pull`。

## 启动

先按 `2_fpga/0_diaplay_test/doc/action_v1_status.md` 在板上安全切换到配对的新动作应用。
仅运行本工具不能改写PL，也不能让旧视频Overlay自动获得动作接口。

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File E:/competition/8_tools/EES331_Action_Viewer_v1.0/Start_Action_Verification.ps1
```

直接双击相邻目录中的EXE默认仍为仅显示/识别模式，日志为`protocol=null`。启用动作需使用上述启动器、v1.4内部“打开动作识别”按钮或显式`--action-control`。
界面显示动作链路是否就绪、PS/AXI完成序号及错误；未连接时不会默认为下发成功。
关闭其他占用UDP5000的接收器。本工具不占用COM4，可另开只读串口工具9600/8N1抓帧；
自动串口验收时需关闭其他占用COM4的工具。

## 行为

- Down/Stop/Thumbs Down/Thumbs up/Up：三个新推理帧连续同类且每帧置信度>=0.75才下发一次。
- Left/Right：本版不自动下发；硬件代码仍保留供人工注入验证。
- 同动作持续时不周期重复发送；切换动作需重新连续三帧。无有效动作一秒发送一次CLEAR。
- 启动和正常关闭各发送一次CLEAR。UDP确认超时会锁定错误，停止新动作，不能假定灯已熄灭。
- 动作为 PC→网络→PS→AXI-Lite→PL LED/UART；不是 PC 直接写 COM4。

COM4帧：`A5 5A SEQ8 ACTION CRC8 0D 0A`。
动作：0全灭，1 Down/LED1，2 Left/LED2，3 Right/LED3，4 Stop/LED4，
5 Thumbs Down/LED5，6 Thumbs up/LED6，7 Up/LED7。V4为原摄像头配置完成灯。
串口完整帧发完才由PL置DONE，PS确认后界面记录完成。

日志自动保存在 `E:/competition/4_metrics/logs/<时间>_gesture_viewer_run01/`，
包含推理、决策、PS确认、错误和关闭结果。未进行动作输出的模式仍可用于视频/模型验证。
日志中 `ACTION_CONFIRMED` 是PS报告PL执行完成，不等同于已采集到COM4物理字节。

本版不接蓝牙主数据流，不驱动机械臂，没有断链硬件安全保证。原SD自启动和`ees331-camera`服务不变；动作版不设为开机自启。完整上板步骤见`1_docs/doc/ees331_pl_reloader_v14_board_guide_2026-09-13.md`。
